# Функциональность записи видео с детекцией

## Описание

Добавлена возможность записи видео с отображением результатов детекции людей и лиц в реальном времени. Запись работает как для камер, так и для видеофайлов.

## Основные возможности

### 1. Запись видео с камер

- Кнопка "Начать запись видео" в панели управления камерами
- Запись включает все элементы детекции: рамки людей, лица, ID треков
- Автоматическое именование файлов с временными метками
- Статус записи отображается в интерфейсе

### 2. Запись видео с видеофайлов

- Кнопка "Начать запись видео" в панели управления видео
- Запись обработанного видео с детекцией
- Поддержка ROI (области интереса)
- Сохранение в папку recordings/

### 3. Настройки записи

- FPS: 30 кадров в секунду (настраивается в config.py)
- Кодек: MP4V (настраивается в config.py)
- Качество: 80% (настраивается в config.py)
- Максимальная длительность: 1 час (настраивается в config.py)

## Техническая реализация

### Класс VideoRecorder

```python
class VideoRecorder:
    def __init__(self, output_path, fps=30, codec='mp4v', quality=80)
    def start_recording(self, frame_width, frame_height)
    def write_frame(self, frame)
    def stop_recording(self)
    def is_active(self)
```

### Интеграция с потоками

- **VideoProcessingThread**: добавлены методы `start_video_recording()`, `stop_video_recording()`, `is_video_recording()`
- **CameraThread**: аналогичные методы для записи с камер
- Сигналы `recording_status_changed` для обновления UI

### Интерфейс

- Кнопки записи в обеих вкладках (Камеры и Видео)
- Индикаторы статуса записи
- Автоматическое обновление состояния кнопок

## Использование

### Для камер:

1. Запустите камеру
2. Нажмите "Начать запись видео"
3. Запись начнется с текущего кадра
4. Для остановки нажмите "Остановить запись видео"

### Для видеофайлов:

1. Загрузите и запустите видео
2. Нажмите "Начать запись видео"
3. Запись начнется с текущего кадра
4. Для остановки нажмите "Остановить запись видео"

## Файлы записи

Записи сохраняются в папку `recordings/` с именами:

- Камеры: `camera_recording_{имя_камеры}_{timestamp}.mp4`
- Видео: `video_recording_{имя_файла}_{timestamp}.mp4`

## Настройки в config.py

```python
# === НАСТРОЙКИ ЗАПИСИ ВИДЕО ===
VIDEO_RECORDING_ENABLED = True      # Включение/выключение записи видео
VIDEO_RECORDING_FPS = 30            # FPS для записи видео
VIDEO_RECORDING_CODEC = 'mp4v'      # Кодек для записи (mp4v, avc1, XVID)
VIDEO_RECORDING_QUALITY = 80        # Качество записи (0-100)
VIDEO_RECORDING_MAX_DURATION = 3600 # Максимальная длительность записи в секундах
```

## Обработка ошибок

- Автоматическая остановка записи при достижении максимальной длительности
- Логирование ошибок записи
- Graceful shutdown при остановке потоков
- Проверка доступности кадров перед началом записи

## Производительность

- Запись выполняется асинхронно в основном потоке обработки
- Минимальное влияние на производительность детекции
- Автоматическое освобождение ресурсов при остановке
